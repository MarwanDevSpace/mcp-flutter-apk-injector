# v0.7.0 — Advanced Reverse Engineering Intelligence & Glama 5.0/5.0 MCP Contracts

## Summary

v0.7.0 elevates **mcp-flutter-apk-injector** to advanced reverse-engineering intelligence while raising all 9 MCP tools to **5.0/5.0 Tier A+** according to Glama quality evaluation standards.

## Key enhancements

| Area | Enhancement |
|---|---|
| **Deep security analysis** | `analyze_injection_surface` now detects anti-debugging (`Debug.isDebuggerConnected()`, `TracerPid`), root checks (`RootBeer`, `su` binary execution, `test-keys`, `Magisk`), SSL pinning (`CertificatePinner`, custom `TrustManager`), and native packers (`Tencent Legu`, `Qihoo 360`, `Bangcle/SecNeo`, `Ijiami`, `DexGuard`, `ProGuard/R8`). |
| **Native library mapping** | Automatic inspection and mapping of `.so` libraries partitioned by native ABI (`arm64-v8a`, `armeabi-v7a`, `x86`, `x86_64`). |
| **Manifest security audit** | Automatic vulnerability scan of `android:debuggable`, `android:allowBackup`, `android:usesCleartextTraffic`, exported components, and dangerous Android permissions. |
| **Multi-DEX traversal** | Full support and classification for multi-DEX workspaces (`smali`, `smali_classes2`, `smali_classes3`, etc.). |
| **Agent tool contracts** | `get_agent_context`, `update_agent_memory`, and `query_memory_graph` now register full typed input/output schemas, behavioral annotations, dual `content` + `structuredContent` responses, and Glama 5.0/5.0 descriptions. |
| **Enhanced query graph** | `query_memory_graph` indexes security findings, native libraries, multi-DEX roots, patch history, and agent notes with relevance ranking. |
| **Glama 5.0 descriptions** | Every tool description satisfies all six Glama rubric dimensions: Behavior, Conciseness, Completeness, Parameters, Purpose, and Usage Guidelines. |
