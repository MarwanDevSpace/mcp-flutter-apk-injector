# v0.6.0 — Enhanced MCP Contracts and Workspace Integrity

## Summary

v0.6.0 upgrades the public MCP contract and repository workspace guidance. It introduces typed output schemas, behavioral annotations, human-readable titles, concise tool-selection guidance, aligned Gemini/agent files, safer forwarding of injection options, additional evidence-first prompts, and a repeatable quality/release checklist.

## Notable changes

| Area | Change |
|---|---|
| Tool definitions | All six primary pipeline tools now register human-readable titles, input schemas, typed output schemas, and behavior annotations. |
| Structured responses | Primary tool handlers return both readable JSON text and MCP `structuredContent`. |
| Injection options | `attachBaseContextHook` and `nativeLibraryFallback` are forwarded from the public schema into the injector. The attach-base-context hook is attempted only for `direct_application_hook`; unavailable target methods become warnings. |
| Smali generation | Native-library fallback can generate a defensive library-load path that returns from generated initialization instead of crashing immediately on a library-load failure. |
| Runtime guidance | Root `GEMINI.md` is canonical. The embedded persona resolves it before `.agents/AGENTS.md`, and the compatibility file is synchronized in this release. |
| Prompt surface | `/merge` and `/revert` are registered as evidence/planning commands. They do not claim unsupported split-merging or rollback behavior. |
| CI | CI now includes `npm pack --dry-run` after build. |
| Registry quality | The stale Glama `v0.1.2` release state is captured as a baseline and is an explicit public-release verification gate. |

## Migration notes

Existing tool names and input fields remain stable. Clients can now use the registered output schemas and annotations to select tools safely. Consumers should read the structured result when available; the JSON text content is retained for backward compatibility.

The `view_tree_injection` input mode remains available but is now documented as experimental. Prefer `activity_overlay` when a cached-engine screen is suitable.

## Validation required before public distribution

Run linting, type checking, tests, build, and package dry-run. Then verify the tool registration contract, GitHub Release/tag/package version consistency, and Glama registry refresh. Publishing to npm or changing public registry state is intentionally outside this code change and requires explicit owner approval.
